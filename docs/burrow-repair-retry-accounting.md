# Emergency shell repair retry accounting

The Site 3 baseline (trial 715) stopped AmberRobin after six confirmed shell
repairs with `Bounded repair exhausted`. The repair counter included successful
placements, so productive repairs consumed the limit intended to stop repeated
failed interactions.

Confirmed placements now clear the consecutive placement-attempt counter. The
original 15-second recovery deadline remains fixed across the entire damaged
shell; six unconfirmed placement attempts still stop recovery. Real inventory,
verified ownership, stable footing, visible support, dry neighbors and private
plot protections remain required.

Regression coverage verifies more than six confirmed repairs can proceed within
the same deadline, that the deadline cannot be extended by placements, and that
six refused roof placements still terminate without granting progress.

This does not resolve every refuge failure. OpalWren in the same trial stopped
with a remaining diagonal breach and no visible supporting face. A read-only
world inspection confirmed that remaining corner had no directly visible face
from the diagnostic shaft position. The terminal body position was not recorded,
so this is not proof that a different safe stance was available.
