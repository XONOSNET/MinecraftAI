# Teacher floor return regression

Evaluation of teacher run `world-1793379497516417600` found seven bots stopped with `floor: No safe stance beside the unfinished floor`. Their preceding positions were 19–74 blocks from home at the end of gathering. This was a controller regression introduced with the floor placement recovery: its 12-block local stance route check ran before the bot returned from a long resource trip. The original native recovery fixture began at the house and missed that transition.

The floor builder now delegates the distant return to the existing expedition/home navigator first, aiming for the safe exterior rather than a potentially dug center-floor tile. Only after arriving near the house does it evaluate local floor placement stances. Truly blocked returns retain an explicit return-route error; placement rejection recovery, safe digging and the bounded retry count are preserved.

Validation: all 323 JavaScript tests passed. New regressions cover 19-, 39- and 74-block returns with unloaded home terrain, transition from return into actual floor work, and accurate reporting of a blocked return. A native fixture completed a real 20-block return and real server-acknowledged floor placement in 6.112 seconds without teleporting during the route. The temporary fixture was cleaned up and wrote no production training data. Result: docs/floor-return-native.json.
