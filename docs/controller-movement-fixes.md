# Controller recovery, harvesting and downhill travel

AmberRobin (LabAI2) was still reporting the previous controller activity, floor, while a subsequent trial had placed the bots into spectator survey mode. A live entity census confirmed game mode 3 and the invisible/glowing entity flags. Heartbeats were active but there was no result report for this bot in the current trial. An unresolved native interaction prevented the decision loop from reading its new assignment.

Hut placement now aims through the existing bounded smooth-look routine, then sends the native placement without another unbounded look wait. The server must still acknowledge and verify the placement. A per-connection guard retires a pending controller when its assignment changes or a single action lasts over 180 seconds. The old connection cannot make subsequent lab API writes. Reconnection creates a fresh controller which surveys and enters survival normally; this grants no inventory or milestones. This is an infrastructure deadline, not a time limit for ordinary slow exploration, which consists of short decisions.

Gathering prioritizes a visible, in-reach log from safe current footing over a historical approach coordinate and nearby loose wood. It retains the trunk lock and cuts the remaining reachable logs before walking out to collect drops. Alignment/wait policy actions at a reachable target cannot walk, jump or strafe away from the working stance. The policy still must select harvesting, and native break times and server removal checks still apply.

Downhill navigation skips an uphill recenter only when the immediate one-block descent has a checked body corridor. A grounded reply just beyond a landing can advance a passed waypoint only on a straight continuation with current solid footing and a checked forward corridor. Corners and lateral travel along a ledge retain centering. This corrects delayed landing updates without permitting arbitrary falls or cutting corners.

Validation: 303 JavaScript tests, including stale native-action recovery, resource/pickup priority, stationary work, downhill departure and late landing regression cases. Isolated native terrace testing initially reproduced four backward segments in 6.355 seconds. After the landing correction it reached the same goal in 4.388 seconds with zero backward segments, removed four stacked logs with 0.138 block displacement, and verified a real plank placement. These are controller diagnostics, not evidence of neural learning gains. The fixture and dropped items were cleaned up. See movement-native.json and scripts/verify_movement_native.cjs.
